# building-distribution

来源：Ryan（@ryangrowthh），[Distribution 101: A Guide to Reaching Millions](https://x.com/ryangrowthh/status/2111080389565640897)（2026-10-16）。把来源 URL 写进产物文件头部。

核心主张：从零做自然流量（organic reach）并不复杂。完整框架 = **讲故事 → 选载体 → 包装 → 排版**，再加几条增长习惯。

## 何时用

- 用户要从零建立受众、品牌或获客渠道。
- `product-creator` 走到第 7 步（Send traffic）：本 skill 是第 7 步的详细指引，产物写入该产品文件夹的 `07-traffic.md`（见下文「与 product-creator 联动」）。

## 输入（先收集，缺的就问一次，别硬编）

- 产品/品牌是什么、卖给谁（若来自 product-creator，直接读 `02-dream-customer.md`、`03-promise.md`、`05-case-study.md`）。
- 用户擅长写、说还是出镜；每周能投入多少小时。
- 受众已经在哪些平台活跃；用户已有的账号和粉丝。
- 该想法的硬约束（例如某平台只做纯分享、不提产品/付费；以 `IDEA.md` / `PROGRESS.md` 或用户当次说明为准，写入计划时必须遵守）。

## 步骤一：搭建要讲的故事（Building a Story）

品牌/分发 = 一连串「章节」，嵌在一个更大的宏观故事里；每条内容是带观众往前走的一步。好故事同时做到三件事：让人有**感受**（情绪）、有**收获**（价值）、想**看下去**（好奇）。

1. **宏观图景**——回答七个问题，写成一份简短 story brief：
   - 你是谁 → 你做什么
   - 从哪里开始 → 起点/「之前」的状态
   - 你相信什么 → 更大的主张
   - 为谁做 → 受众及其困境
   - 为什么是你 → 优势、经历、权威
   - 要去哪里 → 使命/终点
   - 回报是什么 → 产品、品牌或社群
2. **从终点倒推章节**——先写「终点」，再倒推 3–5 个章节与要植入的信念。参考写法：
   - 终点 → 信念 1 → 信念 2 → 信念 3（最后一条指向产品带来的好处）。
   - 原文案例：Wispr Flow 以「Jarvis 式语音操控电脑」为终点，每章指向它；Tesla 2006「秘密宏图」先公开终点，再列 Roadster → Model S → Model 3 → 清洁能源。
   - 产品路线图 = 故事路线图：每个功能/发布/里程碑都是一章。个人品牌则「你自己的成长」就是故事：可以是边做边讲，也可以讲已走完的路；常常两者混合。故事会演化，但终点要先定。
3. **找到声音（Voice）**——故事是「说什么」，声音是「怎么说」：个性是什么、绝不会说什么、语气/语法/品牌口吻。个人品牌：尽量真实，用平常说话方式，**避免用 AI 代写**；想被看成专业还是有趣，声音就匹配那种感知。

产出：`story brief`（宏观图景 + 终点 + 章节清单 + 声音守则）。

## 步骤二：选载体（Selecting Vehicles）

载体 = 分发故事的渠道。三类：

- **Rented（租来的）**：X、TikTok、IG、YouTube——用来获取触达。
- **Owned（自有的）**：邮件列表/Newsletter、社群、网站——用来建立信任、促成转化。
- **Earned（借来的）**：合作、播客、别人的受众——用来获取心智和网络效应。

要做出规模，三类都要，并覆盖漏斗上（TOF）、中（MOF）、下（BOF）内容。**起步只选 1–2 个平台。**

选择三问：
1. 我的受众已经在哪里？（受众最集中的平台，TAM 最大）
2. 我更擅长写、说，还是出镜？
3. 我现实中每周能投入多少时间做内容？

平台速览（原文表格 + 说明）：

| 载体 | 适合 | 漏斗 | 投入 |
|---|---|---|---|
| X | 想法、人脉；快速试验想法再外推到其他渠道 | TOF/MOF | 低–中 |
| 短视频（TikTok/Reels/Shorts） | 纯触达；个人品牌、想快速涨 | TOF | 中 |
| YouTube 长视频 | 深度、信任、搜索；起步慢但复利最强 | TOF/MOF/BOF | 高 |
| LinkedIn | B2B/职场；竞争比 X 小、受众有购买力 | TOF/MOF | 低–中 |
| Newsletter | 信任与转化；发出后立刻有最高互动 | MOF/BOF | 中 |
| 播客 | 权威与深度，能「借」受众 | MOF | 高（自办）/低（做嘉宾） |
| 社群（Discord/Telegram/Skool 等） | 留存、忠诚、一对一 | BOF | 高 |

每个载体承担故事的不同工作：租来的平台带来发现，自有的建立信任，社群更私人。可按平台分配叙事重心（例如 X 偏产品、IG 偏生活方式、社群最私人）。

产出：`vehicle plan`——选定的 1–2 个主渠道 + 理由；以及后续要补的 Owned / Earned 渠道。

## 步骤三：包装（Packaging）

很多人 95% 时间做内容、5% 做包装；应接近 **50/50**。故事再好、载体再对，包装差也只有几百次浏览。

1. **钩子（Hook）**——至少满足其一：大胆论断、点名受众（callout）、好奇缺口、明确结果、反常识。
2. **标题**——大承诺、清晰结果、不让人想「这什么意思」；清晰高于一切。
3. **缩略图/视觉**——唯一任务是让人点开；越简越好。
4. **视频前 3 秒**——钩子不止文字，还有画面和表达：干净背景/布景、必要的剪辑与视觉、屏幕文字强化钩子。

产出：针对所选平台的 **10 个钩子 + 5 个标题草稿**，供用户挑选。

## 步骤四：排版（Formatting）

- **Native**：每个平台有自己的语言，多看爆款形式再迁移（X 可能是长文；LinkedIn 是更偏个人故事的长帖）。
- **Scannable**：信息图、要点、短句；写到 10 岁小孩也能看懂。

## 增长习惯（写进每周计划）

- 经营网络：不只发，要真的在平台上互动（尤其 X 这类文字平台）。
- 偷形式，不偷内容：观察相邻领域的形式，迁移到自己领域。
- 对异常值加倍：某条爆了，就做 5 个变体，不要觉得「已经发过」。
- 渠道互相导流：X → Newsletter、YouTube → X 等。
- 一个想法拆成多份：一篇文章可拆成多个渠道的素材。

## 产出文件（建议结构）

```markdown
# Distribution Plan
- 来源：https://x.com/ryangrowthh/status/2111080389565640897
## 1. Story brief（七问 + 终点 + 章节 + 声音）
## 2. Vehicle plan（Rented / Owned / Earned，主渠道 1–2 个）
## 3. Packaging（钩子、标题、视觉要点）
## 4. Formatting（各平台 native 规则）
## 5. 每周节奏（内容频次、推广位、链接放哪、导流关系）
## 6. 增长动作与复盘（爆款复制、互动、拆分复用）
```

## 节奏

- 一轮只推进一个步骤；用户确认当步产物后再进入下一步。
- 用户面向沟通默认中文。
- 不要凭空编造数据或案例；引用原文案例要标明出处是原文，不要补充未核实的数字。
- 原文自述「1M+ impressions on X in 10 days」只是作者自述，勿当作可承诺结果。

## 与 product-creator 联动

- product-creator 第 7 步调用本 skill：读取 `02/03/04/05` 号文件作为输入，按「故事 → 载体 → 包装 → 排版 → 每周节奏」完成，并把最终计划写入产品文件夹的 `07-traffic.md`（可在其中分节保留 story brief、vehicle plan 等）。
- 完成后在 `PROGRESS.md` 更新 `next_action`（下一周要发的内容/推广位）。

## 完成标准

- 有 story brief、1–2 个主渠道、至少一组钩子/标题、一份每周节奏。
- 文件已落盘，路径已告知用户，`PROGRESS.md`（如存在）已更新。
