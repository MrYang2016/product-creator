# product-creator

这是 **product-creator** agent skill：根据 Hussain Ibarra 的文章 [How to build a profitable digital product (in 7 steps)](https://x.com/HussainIbarra/article/2108563595676299429)，一步步把数字产品想法落地并销售。

每个想法单独放在 `/home/box/agent-data/digital-products/<idea-slug>/` 目录下，并用 `PROGRESS.md` 记录进度，方便中断后继续。

详见根目录 `SKILL.md`。
